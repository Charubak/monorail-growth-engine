# Funnel Library: DeFi-heavy acquisition funnel reference

Used by the Acquisition Funnel Map deliverable. Pick the niche template, adapt to the project, and always name the killer step (the one silently eating most arrivals - in DeFi it is almost always the funding step).

## The master funnel (every variant derives from this)

Source → Click → Landing → Identity (email / social / wallet connect) → Funding (deposit / bridge / mint) → First core action → Repeat (D7) → Referral/loop

Per stage, the doc must state: the conversion metric, the realistic benchmark question to validate, and the single fix hypothesis. Time-to-first-core-action is the master metric across all niches.

## Niche templates

**Perp DEX:** X ads/KOL/competition → landing → connect wallet → bridge + deposit collateral (KILLER STEP: arrivals rarely hold chain-native assets; embedded bridge+swap or paymaster gas = the fix) → first trade → trading volume D7 → points/referral. Users live in: trading CT, perps alpha Telegrams, competitor DEX Discords, funding-rate/stats dashboards (Dune, CoinGlass audiences), trading competitions, perp-focused newsletters.

**Prediction market:** creator content / news moment → SHAREABLE MARKET PAGE as landing (the market itself is the ad) → walletless browse and contest entry → wallet → deposit → first position → event-driven re-engagement (the post-event cliff is the retention problem; plan the next event before this one ends). Users: sports/politics CT, betting Telegrams and tipster communities (compliance care), Polymarket/Kalshi user migration, event-specific subreddits, free-to-play contest players.

**Lending / borrowing:** yield aggregators (DefiLlama Yields, vaults.fyi) and APY comparison content → APY landing → connect → deposit (KILLER STEP: trust; audits and TVL social proof above the fold) → loop/leverage power usage → rate-alert re-engagement. Users: yield-farming Telegrams, DeFi Substacks, governance forums of adjacent money markets, stablecoin communities, onchain targeting (wallets active on competitor protocols, reached via the communities they cluster in).

**RWA / institutional DeFi:** report/newsletter/LinkedIn → educational content → waitlist + KYC (KILLER STEP: KYC drop-off; stage it after value is shown, not before) → onboarding (sometimes human) → deposit → recurring allocation. Users: TradFi-crypto crossover newsletters, LinkedIn (unusually, yes), conferences, treasury/DAO forums, RWA research Substacks.

**Liquid staking / yield products:** wallet and aggregator integrations ARE the funnel (being listed where users already are beats ads) → APY landing → stake → restake/compound loop. Users: staking dashboards, wallet discover tabs, validator communities, airdrop-meta CT.

**L1/L2 ecosystem:** dual funnel. Users: quests/bridge campaign → bridge (killer step) → first app interaction → multi-app retention. Builders: hackathons/grants → deploy → their users become yours. Users: ecosystem CT, chain-native Telegrams/Discords, quest platforms (Galxe/Zealy/Layer3), airdrop farmers (high volume, low retention - design incentives for actions not signups).

## Persona dimensions (for the User Signal Map)

Build each persona across four axes, then attach signals and locations:

1. **Crypto-nativeness:** degen (lives onchain, airdrop-aware, meme-literate) / pro trader (CEX-first, cares about execution and fees) / DeFi power user (yield loops, governance) / TradFi-curious (needs trust signals, KYC-tolerant) / mainstream (domain-first, e.g. football fan; zero wallet assumed)
2. **Capital size:** shrimp (<$1K, volume play, incentive-sensitive) / dolphin ($1K-50K, the usual core) / whale (>$50K, reached 1:1 or via credibility, never via ads)
3. **Motivation:** yield / speculation / airdrop farming / entertainment / ideology / professional edge. Design the hook per motivation, and never build incentives that only attract the farmer persona.
4. **Behavior signals:** onchain (which protocols and chains they already use - Dune-queryable; competitor users are the warmest cold audience) and social (who they follow, which newsletters they read, which communities they post in vs lurk)

Per persona, the map states: identifying signals, named live communities (verify activity before outreach), the converting hook, the funnel variant they enter, and their estimated share of the target mix. The mix drives budget split downstream.

## Where users live (source map, ranked by typical CAC)

1. Owned/earned: shareable product moments, data content quoted as news, SEO/AEO for intent niches
2. Communities: niche Telegrams and Discords (alpha groups, competitor communities), governance forums, subreddits
3. Newsletters: sponsoring established crypto Substacks/Beehiivs is routinely cheaper per qualified reader than X ads; also guest essays and cross-promos
4. Creators/KOLs: per the creator plan
5. Quest platforms: volume with retention risk; tie rewards to core actions only
6. Paid ads: X/Reddit first; surrogate strategy if compliance-restricted
7. Aggregators/integrations: DefiLlama, wallets, dapp stores - distribution that compounds

## Newsletter module (owned audience strategy)

When warranted (most projects with >3-month horizons): lead magnet from the project's own data ("what the market/chain is telling us" briefs), Beehiiv setup, weekly cadence tied to the content calendar, growth via sponsorship swaps with adjacent niche newsletters, sponsor placements bought in 2-3 established ones (ask their real CPMs - feed the receipts database), and the list doubles as the retention channel for post-event cliffs.
