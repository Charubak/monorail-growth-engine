# charubak-growth-engine

An AI agent system that runs the entire first week of a Web3 growth engagement the way Charubak Chakrabarti does it. Built as a Claude skill, battle-tested on a live sports prediction market during the 2026 World Cup.

**What it produces per engagement:** per-product content guidelines, nearest-peer competitive recon (+ ecosystem allies), a budget-tiered creator plan (20 named targets), a timestamp-verified narrative digest, an outside-in funnel teardown with validation metrics, a compliant ads/surrogate concept (only when ads are warranted), and an outreach email in Charubak's calibrated voice.

**Design principles:** sourced and dated or it doesn't ship; founder-readable (700–950 words/doc); estimates labeled as estimates; the non-crypto domain (football, gaming, etc.) researched with equal depth; budget reality before recommendations; a hard 24–48h narrative freshness gate; reliability tiers stated honestly (AI delivers / AI assists / human only); and an iteration log that updates the playbook after every run.

**Files:** `SKILL.md` (the agent), `ITERATION-LOG.md` (lessons per engagement, read before every run).

**Usage:** install as a Claude skill (Cowork/Claude Code), then: `run the engagement for [project]`.
